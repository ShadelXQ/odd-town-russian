## Русификатор Odd Town v1.0

Первый публичный релиз полного русского перевода игры.

### Что внутри

- **~1300 строк** диалогов и реплик персонажей.
- **Все 191 строки** локализации: меню, настройки, HUD, загрузка/сохранение, подсказки, названия предметов.
- **Шрифт Press Start 2P с кириллицей** (178 глифов) вместо урезанной версии без русских букв.

### Установка

1. Скачайте `Odd_Town_RU_v1.0.zip` ниже и распакуйте.
2. Скопируйте `zzz_Localizer_PixelCity-Windows_P.pak` в папку игры:

   ```
   <папка игры>/PixelCity/Content/Paks/
   ```

3. Если файл с таким именем уже есть — сделайте его копию и замените нашим.
4. Запустите игру.

### Удаление

Удалите `zzz_Localizer_PixelCity-Windows_P.pak` из папки `Paks/`.

### Известные проблемы

Перевод ещё в работе: местами возможны опечатки, неудачные формулировки, непереведённые строки, а также проблемы с отображением шрифта (слишком длинный текст, обрезание в меню). Мы о них знаем и постепенно исправляем — обновления будут выходить по мере готовности.

Если что-то заметили — напишите в [Issues](https://github.com/ShadelXQ/odd-town-russian/issues) с указанием экрана или персонажа.

### Совместимость

Проверено на версии игры **1.0.1**. Пак не содержит файлов самой игры — только изменённые ресурсы перевода.
