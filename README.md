# Русификатор Odd Town

Полный русский перевод игры **Odd Town**: диалоги, реплики NPC, меню, HUD и элементы интерфейса.

![version](https://img.shields.io/badge/version-1.0-blue)
![game](https://img.shields.io/badge/game-1.0.1-green)

## Установка

1. Скачайте `Odd_Town_RU_v1.0.2 zip` из раздела [Releases](../../releases).
2. Распакуйте архив.
3. Скопируйте `zzz_Localizer_PixelCity-Windows_P.pak` в папку:

   ```
   <папка игры>/PixelCity/Content/Paks/
   ```

   (рядом с файлом `PixelCity-Windows.pak`)

4. Запустите игру.

Если файл с таким именем уже есть — сначала сделайте его копию, затем замените нашим.

## Удаление

Удалите `zzz_Localizer_PixelCity-Windows_P.pak` из папки `PixelCity/Content/Paks/` — игра вернётся к оригинальному английскому.

## Что переведено

- **~1300 строк** диалогов и реплик персонажей (Мишель, Пьер, Ленни Физзлбэнг, Югетт, Жюстин, Клод, Элиот, Лукас, Кевин и другие).
- **Все 191 строки** локализации: меню, настройки, HUD, загрузка/сохранение, подсказки, названия предметов.
- **Шрифт** заменён на полный Press Start 2P с кириллицей (178 глифов). В оригинале лежала урезанная версия без русских букв.

Намеренно не переведены: название игры «Odd Town», имя камеры и номер версии.

## Известные проблемы

Перевод ещё в работе: местами возможны опечатки, неудачные формулировки, непереведённые строки, а также проблемы с отображением шрифта (слишком длинный текст, обрезание в меню). Мы о них знаем и постепенно исправляем — обновления будут выходить по мере готовности.

Если что-то заметили — напишите в [Issues](../../issues) с указанием экрана или персонажа, это сильно ускорит правки.

## Совместимость

Перевод сделан и проверен на версии игры **1.0.1** (сборка с файлом `PixelCity-Windows.pak`).

Пак не содержит файлов самой игры — только изменённые ресурсы перевода.

## Технические детали

- Формат: Unreal Engine `.pak` (V11), без сжатия.
- Путь монтирования: `../../../`.
- Внутри: 93 изменённых `.uexp`/`.uasset`/`.umap`, `Game.locres` и шрифт `PixelGrunge.ufont`.
- SHA-256 пака указан в `SHA256.txt` внутри архива.
